## 📖 项目简介

本系统围绕自助终端金融交易与外设集成场景设计，服务端基于中国银联 ISO8583 报文协议，实现银联卡（信用卡或储蓄卡）、社保个账（实体社保卡或电子医保码）的消费、冲正、退费、个账余额查询、电子医保码解码等金融交易，并对接身份证读卡器、社保卡读卡器、银行卡读卡器、密码键盘、小票机、普通打印机等硬件外设。

系统提供统一的 HTTP 接口：银联交易与硬件外设接口采用 `code=0` 表示成功、`code!=0` 表示失败的返回结构；所有接口均采用 JSON 交互。仓库用于展示系统接口能力、集成文档与示例说明，方便合作伙伴评估与联调。

商户侧无需从零实现 ISO8583 组包解包与银联交易接口，只需向收单银行申请银联商户号、终端号、密码键盘密钥信息，完成终端绑定、签到与密钥注入后，即可通过本系统发起金融交易。具体准入、终端绑定与密钥管理要求以收单机构为准。

## ⭐ 重点能力

- 💰 **银联交易**：终端签到、签到 Key 注入与校验、账户余额查询、消费、冲正、退费、电子医保码验证。
- 💳 **社保卡信息读取**：读卡器初始化/释放、设备信息、卡信息、持卡人信息、社保账户信息读取（需输入社保卡密码）。已适配德卡、强氏、创自等厂商读卡器设备。
- 🏧 **银联卡信息读取**：银行卡读卡器初始化/释放、设备信息、卡号、有效期、服务代码、序列号、磁轨数据、55 域、48 域、读卡数据读取。已适配德卡、强氏、创自等厂商读卡器设备。
- 👤 **医保刷脸与电子凭证**：电子凭证业务调用、二维码解码、终端二维码解码、刷脸身份授权、刷脸身份信息获取、刷脸认证、终端读取身份证信息、刷脸核身。
- 🆔 **身份证读卡**：身份证读卡器设备信息获取，读取姓名、性别、民族、地址、出生日期、身份证号、有效期起始/结束日期、签发机关等信息，可用于实名核验、自助业务身份确认及医保刷脸流程中的身份信息读取。
- 🧾 **小票打印**：小票机设备状态、XML 打印模板、文本/条码/二维码/走纸/切纸、打印前缺纸检查。票据/小票打印已适配研科、美松等厂商设备。
- 🖨️ **报告/发票文件打印**：打印机列表与默认打印机设置、本地/网络/Base64 文件打印、A2-A6 纸张、横打/竖打、打印机状态、耗材状态、唤醒打印机。

### 💰 1. 银联交易

系统基于中国银联 ISO8583 报文协议封装交易接口，支持：

- 🔐 银联终端签到，返回 PinKey、MacKey、校验码与签到时间；
- 🔑 签到 Key 注入与校验；
- 💰 社保个账余额查询，返回账面余额与可用余额；
- 🛒 银联消费交易（支持储蓄卡/信用卡/社保卡/电子医保）；
- ↩️ 冲正消费交易（支持储蓄卡/信用卡/社保卡/电子医保）；
- 💸 银联退费交易（支持储蓄卡/信用卡/社保卡/电子医保）；
- 📱 电子医保码验证与解码。

消费、冲正、退费接口支持商户号、终端号、卡代码、卡类型、主账号、交易金额、交易单号、原检索参考号、退款单号等参数，并返回系统跟踪号、检索参考号、批次号、交易日期时间、55 域、61 域、受理机构标识码等交易结果信息。

### 💳 2. 社保卡信息读取

支持实体社保卡读卡器完整生命周期管理：

- 🔌 初始化读卡器、释放读卡器资源；
- 📟 获取设备唯一标识、版本号、设备状态；
- 📇 读取社保卡卡信息：识别码、卡类型、规范版本、发卡机构代码、发卡日期、有效期、卡号；
- 👤 读取持卡人信息：卡号、姓名、性别、民族、出生日期等；
- 💼 读取社保账户信息：医保主账号、PSAM 卡号/终端号/地区代码、应用序列号、应用有效期、服务码、货币代码、国家代码、磁轨数据、48/55 域、读卡数据等，需要输入社保卡密码。

支持读取一代、二代、三代社保卡；读取社保账户信息后，返回的医保主账号、有效期、服务代码、货币代码、国家代码、磁轨数据、55 域、读卡数据等字段可直接用于银联余额查询、消费、冲正、退费等交易接口，无需重复读卡组包。读卡器硬件已支持德卡、强氏、创自等厂商设备，具体型号与固件版本以实际联调确认为准。

### 🏧 3. 银联卡信息读取

支持银行卡读卡器初始化、释放、设备状态查询与卡信息读取，返回：

- 💳 卡类型、卡号、有效期、服务代码、卡序列号；
- 🌍 货币代码、国家代码；
- 📶 磁轨 1/2/3 数据；
- 🔢 55 域、48 域、读卡数据等。

读取结果可直接用于银联消费、冲正、退费等交易接口。银行卡读卡器已适配德卡、强氏、创自等厂商设备，具体型号与固件版本以实际联调确认为准。

### 👤 4. 医保刷脸与电子凭证

支持医保电子凭证与刷脸身份核验相关能力：

- 📞 医保电子凭证业务调用；
- 🔳 电子凭证二维码解码，返回参保人身份证、姓名、证件类型、参保地区编码、电子凭证令牌等；
- 📲 终端电子凭证二维码解码；
- 👤 医保刷脸身份授权；
- 👁️ 获取医保刷脸身份信息；
- ✅ 医保刷脸身份认证；
- 🆔 终端读取身份证信息；
- 🛡️ 医保刷脸核身。

需按当地医保平台要求配置 `api_url`、`orgId`、`businessType`、`operatorId`、`officeId`、`deviceType` 等参数。

### 🆔 5. 身份证与密码键盘

- 🆔 **身份证读卡器**：获取设备信息、读取姓名、性别、民族、地址、出生日期、身份证号、有效期、签发机关等；
- ⌨️ **密码键盘**：打开/关闭键盘、读取键盘序列号/版本/算法模式、扫描按键值，用于密码输入与交易授权流程。

### 🧾 6. 小票打印

小票机支持基于 XML 模板的打印能力：

- 🎨 打印格式设置：行间距、左边距、打印区域、对齐方式、加粗、下划线、字体放大；
- 📝 内容打印、走纸/退纸、换行；
- 📊 一维条码：HRI 位置、字体、高度、宽度、条码类型、条码数据；
- 🔳 二维码：模块大小、纠错等级、二维码数据；
- ✂️ 自动切纸；
- 🔍 打印前状态检查，可配置是否检查缺纸；
- 📟 设备信息查询：连接状态、在线状态、纸耗尽、纸即将耗尽、堵纸、切纸错误等。

票据/小票打印硬件已适配研科、美松等厂商设备，具体型号与固件版本以实际联调确认为准。

### 🖨️ 7. 报告/发票文件打印

普通打印机模块支持：

- 📋 获取打印机列表、获取/设置默认打印机；
- 📄 打印本地文件、网络文件、Base64 文件；
- 📐 文件后缀名、打印机名称、纸张大小 A2/A3/A4/A5/A6、打印方向横打/竖打；
- ⏰ 唤醒打印机；
- 📊 获取打印机状态：就绪、缺纸、打印中、卡纸、门打开、硒鼓未安装等；
- 🎨 获取耗材状态：黑色/青色/红色/黄色墨盒剩余量、总打印页数、单色/彩色打印张数。

适用于自助机报告打印、发票打印、缴费凭证打印等场景。普通文件打印通过系统打印队列支持已安装的打印机。

## 🔄 典型业务流程

1. 🏦 商户向收单银行申请银联商户号、终端号、密码键盘密钥信息；
2. 🚀 部署银联交易服务与硬件外设服务，完成终端绑定、签到和密钥注入；
3. 👤 用户选择银行卡、社保卡、电子医保码或医保刷脸；
4. 📇 通过读卡器/扫码/刷脸获取卡信息、账户信息或医保电子凭证令牌；
5. 💳 调用余额查询、消费、冲正、退费等银联交易接口；
6. 🧾 交易成功后打印小票、报告或发票；
7. 🔁 异常时发起冲正或退费，并记录交易流水与设备状态。
